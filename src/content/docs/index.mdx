## Why agent-md?

Modern software development increasingly relies on LLMs and autonomous AI agents reading, writing, and modifying Markdown documentation. However, conventional Markdown is designed for human visual comfort—packed with decorative characters, padded tables, bold markers, and ASCII art trees that inflate prompt sizes and waste context tokens.

`agent-md` introduces an AI-first Markdown standard with zero-overhead tooling.

<CardGrid stagger>
  <Card title="Token Optimization" icon="rocket">
    Reduces up to **20% of unnecessary tokens** across tables, lists, comments, and directory trees without losing information density.
  </Card>
  <Card title="AI Agent First" icon="setting">
    Designed for autonomous tool execution: structured JSON output, section-level read/write operations, and pre-validation.
  </Card>

## Quick Installation

<Tabs>
  <TabItem label="Homebrew (macOS & Linux)">
```bash
brew tap loclv/tools
brew install agent-md
```
  </TabItem>
  <TabItem label="Cargo">
```bash
cargo install agent-md
```
  </TabItem>
  <TabItem label="Build From Source">
```bash
git clone https://github.com/loclv/agent-md.git
cd agent-md
cargo build --release
# Binary available at target/release/agent-md
```
  </TabItem>
  <TabItem label="Rust Library">
```toml
[dependencies]
agent-md = "0.5.0"
```
  </TabItem>
</Tabs>
